# JDBC and Servlet Practice Project

## 📌 Project Overview

This project is developed to practice and understand **Java Database Connectivity (JDBC)** and **Java Servlets** by building a Java web application connected to a MySQL database.

It focuses on understanding how Java applications communicate with databases, process HTTP requests, and manage data using server-side technologies.

## 🛠️ Technologies Used

- **Java** – Backend programming
- **JDBC** – Database connectivity
- **Servlets** – Handling HTTP requests and responses
- **MySQL** – Relational database management
- **HTML & CSS** – Frontend development
- **Apache Tomcat** – Web application server
- **Eclipse IDE** – Development environment

## ✨ Key Concepts Practiced

- JDBC Driver Configuration
- Database Connection Management
- PreparedStatement and Statement
- Executing SQL Queries
- ResultSet Handling
- Servlet Lifecycle
- doGet() and doPost() Methods
- HTTP Request and Response Handling
- Connecting Servlets with MySQL Database
- CRUD Operations

## ⚙️ Requirements

- JDK 8 or above
- Eclipse IDE
- Apache Tomcat Server
- MySQL Server
- MySQL JDBC Driver

## 🚀 How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/siddusreeyapureddy-29/jdbc-servlet-practice1.git
   ```

2. Open Eclipse IDE.

3. Import the project into Eclipse:
   - File → Import
   - General → Existing Projects into Workspace
   - Select the project folder.

4. Configure the MySQL database connection.

5. Add the MySQL Connector/J library to the project.

6. Configure Apache Tomcat Server in Eclipse.

7. Run the project on the Tomcat server.
